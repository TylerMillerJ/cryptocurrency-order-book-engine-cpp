# C++ Crypto Trading System
## Description
The program runs simulates the experience of buying and selling cryptocurrencies in the command-line in text mode. The program uses a data set representing the order book of a real currency exchange platform.

## Implementation Details

User can create offers and bids into the order book where they are matched.

More details will be added throughout the course and completion of this project, as I am actively learning and implementing various aspects of exchanges and how order books work as part of the course.
